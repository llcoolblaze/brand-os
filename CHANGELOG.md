# Changelog

All notable changes to Brand OS will be documented in this file.

## [0.1.0] - 2026-04-01

### Added
- Initial release of Brand OS
- 29 knowledge base templates across 12 GTM domains
- 15 Claude Code skills (6 GTM + 8 guided setup + 1 content review)
- 7-phase guided setup wizard with progress tracking
- 7 zero-dependency automation scripts
  - health-check: validate frontmatter and cross-references
  - learnings-log/search: GTM insight capture with confidence decay
  - config: persistent user preferences
  - session-summary: session continuity
  - auto-process-all: daily priorities digest
  - post-ingest: auto-fix frontmatter
- Local React dashboard (3 pages: Dashboard, Knowledge Base, Settings)
- Brand voice enforcement with voice-DNA system
- Content review skill with 5 parallel quality checks
- GTM operating principles (ETHOS.md)
- Learnings system with JSONL storage and confidence decay
- Setup script for first-time installation
- ARCHITECTURE.md documenting system design
- CONTRIBUTING.md for open-source contributors
