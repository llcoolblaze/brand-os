## Content Mapping

### Content Types by Funnel Stage

| Funnel Stage | Content Type | Keyword Intent | Conversion Goal |
|-------------|-------------|---------------|----------------|
| **ToFu** (Awareness) | Blog posts, guides, data reports | Informational ("how to", "what is") | Email subscribe, resource download |
| **MoFu** (Consideration) | Comparison pages, case studies, webinars | Investigational ("best", "vs", "review") | Demo request, free trial |

## Technical SEO Checklist

<!-- TODO: Review quarterly -->

### Foundations
- [ ] XML sitemap submitted to Google Search Console
- [ ] Robots.txt configured correctly
- [ ] HTTPS enabled site-wide
- [ ] Mobile-responsive (pass Google Mobile-Friendly Test)
- [ ] Core Web Vitals passing (LCP < 2.5s, FID < 100ms, CLS < 0.1)
- [ ] Canonical tags on all pages
- [ ] Structured data / schema markup on key pages

### On-Page
- [ ] Title tags unique and < 60 characters, include target keyword
- [ ] Meta descriptions unique and < 155 characters, include CTA
- [ ] H1 tag on every page, contains primary keyword
- [ ] Internal linking between cluster pages (5+ internal links per page)
- [ ] Image alt text on all images
- [ ] URL structure is clean and keyword-rich (no random IDs)
- [ ] Content is > 1,500 words for pillar pages

### Performance
- [ ] Page load time < 3 seconds
- [ ] Images optimized (WebP format, lazy loading)
- [ ] No broken links (run monthly audit)
- [ ] No duplicate content issues
